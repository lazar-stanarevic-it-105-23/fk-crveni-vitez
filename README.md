FK Crveni Vitez

Veb sajt napravljen kao moj završni rad za studije na fakultetu Visoka Tehnička Škola Strukovnih Studija u Novom Sadu.

FK Crveni Vitez je veb sajt za fudbalski klub napravljen uz pomoć HTML, CSS, PHP i MySQL tehnologija.
Projekat predstavlja moje znanje o veb razvoju i upravljanju bazama podataka.

Korišćene tehnologije:

HTML
CSS
PHP
MySQL

Odlike:

Nekoliko stranice veb sajta
Navigacioni meni
Responzivni prikaz
Informacije o klubu
Forme za unos i prijavu igrača
Integracija sa bazom podataka

Podešavanje baze podataka:

Instalirati i pokrenuti XAMPP
Promeniti početni port sa 3306 na 3307
Otvoriti phpMyAdmin
Napraviti bazu pod nazivom crveni_vitez
Uneti crveni_vitez.sql u bazu podataka preko Import dugmeta
Prebaciti folder projekta u htdocs direktorijum za XAMPP
Otvoriti veb sajt na novoj kartici:

http://localhost/fk-crveni-vitez/index.html
